# フォロー検索URLメーカー

DLsiteでフォローしているサークルの作品を、検索機能でまとめて見るためのツールです。

サークルIDを `RG22701|RG55089` のように「|」で繋ぐと、複数サークルをOR検索できます。このIDの切り貼りを自動化しました。

**公開ページ**: https://kasairyu.github.io/dlsite-follow-search/

ローカルで使う場合は、`index.html` をダウンロードしてブラウザで開くだけで動きます。

## 使い方

1. DLsiteのフォローリストのページを Ctrl+S(Macは Cmd+S)で保存します。形式は「HTMLのみ」でも「MHTML(.mhtml)」でも使えます。
2. ツールの「保存したHTML/MHTMLを読み込む」から、保存したファイルを選びます。フォローリストが複数ページに分かれている場合は、ファイルをまとめて選べます。
3. サークルページのURLやRGコードを、入力欄に直接貼り付けても使えます。
4. ストア(同人・女性向け・全年齢)、並び順、1ページの件数を選びます。
5. 「DLsiteで開く」を押すと、フォロー中サークルの作品一覧が開きます。

## できること

- RGコードの自動抽出(重複は除外)
- 「RG…|RG…」の文字列のコピー
- サークル数が多い場合は、複数の検索URLに自動で分割
- 入力内容と条件をブラウザに保存(次回は追記するだけで使えます)

## 注意

- 検索URLの形式は、DLsiteの検索の仕様に基づく想定です。開いて結果が出ない場合は、「RG…|RG…」の文字列をコピーして、DLsiteの検索欄に貼り付けてください。
- 検索条件の保存は、DLsiteの「こだわり条件」から検索したあとに行います。
- DLsiteの仕様が変わると、動かなくなることがあります。

## プライバシー

- 入力した内容や読み込んだファイルは、お使いのブラウザの中だけで処理されます。外部のサーバーには送信しません。
- 入力内容と条件は、お使いのブラウザ(localStorage)に保存されます。
- フォントの表示のために、Google Fonts に接続します。
- 読み込んだファイルからは、RGコードだけを取り出して使います。
